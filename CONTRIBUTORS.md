# Contributors

Toplet is built by its community. Thank you to everyone who has contributed code, design,
testing, translations, documentation and ideas.

## Toplet

The full, always-current list is the repository's
[contributors graph](../../graphs/contributors). Add yourself here in your first pull request if
you like (name and optional link), in alphabetical order.

## Upstream

Toplet is a fork of [Atoll](https://github.com/Ebullioscopic/Atoll) by Ebullioscopic and its
contributors, which builds on [boring.notch](https://github.com/TheBoredTeam/boring.notch) by
TheBoredTeam. Their authorship is preserved in the git history and file headers, and their work is
credited in the [README](ReadMe.md#credits) and [NOTICE](NOTICE).
