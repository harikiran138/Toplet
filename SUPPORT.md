# Getting help with Toplet

- **Something is broken?** Open a [bug report](../../issues/new/choose). Include your macOS
  version, Mac model and Toplet version; menu bar icon → **Tools → Export Logs** helps (check the
  logs for anything private first).
- **Have an idea?** Open a [feature request](../../issues/new/choose) and describe the problem it solves.
- **Question about building or contributing?** See [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) and
  [CONTRIBUTING.md](CONTRIBUTING.md), or ask in an issue (Discussions will be enabled once the
  repository is public).
- **Security problem?** Please don't post it publicly — see [SECURITY.md](SECURITY.md).

Toplet is maintained by volunteers. We read everything, but replies can take a few days.
